# aut-rapno

Agentic AI implementation of the RAPNO-directed image analysis

## Organized Pipeline Entry

Run full baseline pipeline (demo):

```bash
.venv/bin/python -m src.agents.orchestrator --use-demo
```

Run full baseline pipeline (real index):

```bash
.venv/bin/python -m src.agents.orchestrator --index-json data_index.json
```

Detailed execution guide:

```bash
.venv/bin/python documentation.py
```
