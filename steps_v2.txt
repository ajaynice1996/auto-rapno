Pediatric Brain Tumor Agentic AI System (v2)

Goal
- Build an agentic AI pipeline for pediatric brain tumor MRI analysis and final report generation.
- Phase 1: Agentic report generation from MRI + segmentation + report templates.
- Phase 2: Train a multimodal model (MRI + segmentation + report) and compare model-generated reports vs agent-generated reports.

-------------------------------------------------------------------------------
WHAT CHANGED IN V2
-------------------------------------------------------------------------------

- Codebase is now organized by functionality under src/ (no separate phase1/step1 source trees).
- Single primary execution entrypoint:
  - src/agents/orchestrator.py
- Dataset, intake, QC, registration, modality, segmentation, quantification, reports,
  and evaluation are split into separate folders for readability and maintenance.

-------------------------------------------------------------------------------
PHASE 1: EXECUTION STEPS (RUNNABLE)
-------------------------------------------------------------------------------

Step 0. Environment setup
- Create a local virtual environment and install minimum required packages.

Commands
- /opt/homebrew/bin/python3 -m venv .venv
- .venv/bin/python -m pip install --upgrade pip
- .venv/bin/python -m pip install nibabel numpy scipy

Step 1. Build/refresh manifest
- Build manifest from data_index.json.

Command
- .venv/bin/python -m src.dataset.create_manifest --index-json data_index.json --output-csv data/metadata/master_manifest.csv

Output
- data/metadata/master_manifest.csv

Step 2. Validate manifest paths
- Validate file existence from manifest rows.

Command
- .venv/bin/python -m src.dataset.validate_dataset --manifest-csv data/metadata/master_manifest.csv --output-csv data/metadata/data_qc_report.csv

Output
- data/metadata/data_qc_report.csv

Step 3. Optional split IDs generation
- Create train/val/test ID files if split column is assigned.

Command
- .venv/bin/python -m src.dataset.split_dataset --manifest-csv data/metadata/master_manifest.csv

Outputs
- data/metadata/train_ids.txt
- data/metadata/val_ids.txt
- data/metadata/test_ids.txt

Step 4. Run full agentic baseline pipeline (recommended)
- Runs intake -> image qc -> registration triage -> missing contrast flags -> segmentation ->
  seg qc -> quantification -> report draft -> report validation -> summary.

Demo command (no external data required)
- .venv/bin/python -m src.agents.orchestrator --use-demo

Real data command
- .venv/bin/python -m src.agents.orchestrator --index-json data_index.json

Key outputs
- outputs/image_intake/modality_inventory.csv
- outputs/image_qc/image_qc_scores.csv
- outputs/registration/registration_triage.csv
- outputs/modality_qc/missing_contrast_flags.csv
- outputs/modality_qc/synthesis_queue.csv
- outputs/segmentation_qc/seg_qc_scores.csv
- outputs/quantification/tumor_metrics.csv
- outputs/report_generation/report_draft_index.csv
- outputs/report_validation/report_validation_results.csv
- outputs/evaluation/phase1_case_summary.csv
- outputs/evaluation/phase1_summary.json

Step 5. Review results with radiologist workflow
- Review draft reports and flags.
- Track edits for future supervised fine-tuning and critic improvement.

-------------------------------------------------------------------------------
PHASE 2: TRAINING ROADMAP (NEXT)
-------------------------------------------------------------------------------

Step 6. Create multimodal training manifests
- Build train/val/test manifests combining MRI paths + segmentation + structured report labels.

Output target
- data/processed/mm_dataset/train_manifest.csv
- data/processed/mm_dataset/val_manifest.csv
- data/processed/mm_dataset/test_manifest.csv

Step 7. Train multimodal model
- Train a model that maps MRI + segmentation (+ optional clinical features) to structured report targets,
  then optional text generation.

Output target
- outputs/models/multimodal_report_model/

Step 8. Compare systems
- Compare:
  - System A: Agentic pipeline output
  - System B: Multimodal trained model output
  - Reference: Radiologist report

Output target
- outputs/evaluation/phase2_agentic_vs_model_comparison.csv
